# دليل إدارة متجر نجد وSupabase

## ما الذي تستخدمه يوميًا؟
أنت لا تحتاج إلى تعديل قاعدة البيانات أو كتابة SQL لإدارة البيع. استخدم لوحة المتجر:
https://najd-cosmetics.glassyplume.chatgpt.site/admin

Supabase هو المكان الذي يحفظ المنتجات والطلبات والحسابات والصور. الأدمن هو الواجهة الأسهل للتعامل مع هذه البيانات. حفظ التعديلات من الأدمن يرسلها إلى Supabase؛ ليست محفوظة فقط على جهازك.

## مهامك اليومية من الأدمن

| المهمة | أين وكيف؟ |
| --- | --- |
| الإعلان المتحرك | إعدادات المتجر ← شريط الإعلانات: فعّل العرض، اكتب النص العربي، وأضف الترجمتين إن رغبت. اختر السرعة، راجع المعاينة ثم اضغط حفظ الإعدادات. افتح المتجر من جديد. |
| صور الغلاف | إعدادات المتجر ← غلاف الصفحة الرئيسية: تغيير الصورة، ترتيب الأغلفة بالأسهم، ثم حفظ الإعدادات. |
| إضافة منتج | المنتجات ← منتج جديد: الاسم والصور والقسم والماركة والسعر والمخزون؛ راجع الترجمة التلقائية ثم انشر واحفظ. المنتج الذي يبقى مسودة لا يظهر للزبائن. |
| الأكثر مبيعًا والمميزة | عدّل المنتج وفعل الخيار المناسب، ثم احفظ. يجب أن يكون منشورًا ومتوفرًا وقسمه ظاهرًا. |
| إضافة صور كثيرة | إضافة بالجملة: اختر الصور، حدد السعر والكمية والقسم، راجع كل منتج قبل الحفظ. كل صورة تُنشئ منتجًا مستقلًا. |
| الأقسام والبراندات | لكل منهما صفحة مستقلة للإضافة والتسمية والترتيب والإخفاء. عند إضافة منتج اختر القسم المطلوب. |
| المدن | المدن والتوصيل: ابحث عن المدينة، أدخل الرسوم الحقيقية، فعّلها ثم احفظ التوصيل. لا تفعل جميع المدن دون مراجعة الرسوم. |
| الطلبات | افتح الطلب، راجع الهاتف والعنوان والمنتجات، ثم غيّر الحالة. إجمالي السعر والمخزون يحسبهما الخادم. لا تعدّل الطلب مباشرة من Supabase. |
| أصحاب الجملة | أنشئ الحساب برقم الهاتف وكلمة مرور، وراجع تفعيله وأسعار الجملة. لا تشارك كلمة المرور في مكان عام. |
| التقارير والموظفون والحماية | اضغط أدوات متقدمة في القائمة لتظهر الأقسام الإضافية. |

الإعلان التجريبي مفعّل الآن. إذا اختفى: تحقق من وجود نص، تفعيل العرض، الضغط على الحفظ، ثم أعد تحميل الصفحة. الشريط يتحرك باستمرار دون زر إيقاف، ولا يتوقف بالمرور أو اللمس. إعداد تقليل الحركة في الجهاز يعرض النص ثابتًا.

## كيف تفتح Supabase؟
1. افتح https://supabase.com/dashboard وسجل الدخول بحساب مالك المشروع.
2. اختر مشروع المتجر. معرف المشروع: `jckwggxyzszljuflvwxr`.
3. هذه الأقسام للمتابعة التقنية؛ لا تحتاج استخدامها لكل عملية بيع:

| القسم | وظيفته في متجرك |
| --- | --- |
| Table Editor | عرض جداول المنتجات products والطلبات orders وإعدادات المتجر store_settings. استخدم الأدمن للتعديل المعتاد. |
| Authentication → Users | حسابات الدخول. وجود حساب وحده لا يمنحه صلاحية إدارة أو أسعار جملة؛ الصلاحيات منفصلة. |
| Storage → products | صور المنتجات. احتفظ بنسخة خارجية من الصور ولا تحذف صورة مستخدمة. |
| Edge Functions | وظائف الخادم مثل checkout وwholesale-accounts. منها تراجع السجلات عند فشل الطلب أو تسجيل الجملة. |
| Database → Backups | افحص النسخ المتاحة وتواريخها حسب خطتك. |
| Logs / Advisors | الأخطاء والتحذيرات التقنية. لا تلغِ الحماية لمجرد إزالة تحذير. |

## حماية الحساب والبيانات
- لا تعطل RLS: هي قواعد تمنع الزائر من قراءة الطلبات أو تعديل المنتجات.
- لا ترسل service_role أو Secret API key لأحد ولا تضعها في ملفات الواجهة. المفتاح العام للواجهة يختلف عنها.
- من الأدمن ← أدوات متقدمة ← المصادقة الثنائية: سجل تطبيق المصادقة، امسح QR، وأدخل الرمز للتحقق. بعد نجاح التسجيل، يمكن إلزام حساب الموظف بـMFA. لا تفعل الإلزام قبل التسجيل.
- حماية دخولك إلى لوحة Supabase نفسها منفصلة عن حماية حساب الأدمن في المتجر؛ فعّل المصادقة الثنائية للحسابين.
- حماية كلمات المرور المسرّبة: راجع إعدادات أمان Authentication في Supabase وتوفر الميزة في خطتك.
- لا تضغط حذف المشروع أو Restore على متجر يعمل دون نسخة وخطة؛ الاستعادة قد ترجع البيانات إلى وقت سابق.

## النسخ الاحتياطي ببساطة
نسخة قاعدة البيانات لا تعني نسخة صور Storage. احتفظ بنسخة منفصلة من الصور والكود، وتحقق من نسخة قاعدة البيانات ومن إمكانية استعادتها. حسب وثائق Supabase، النسخ اليومية متاحة في الخطط المدفوعة المحددة، وتوصي الوثائق أصحاب الخطة المجانية بتصدير دوري خارج المنصة. لم نغيّر خطتك أو نشتر خدمة مدفوعة. تصدير JSON في الأدمن لا ينسخ Auth وملفات الصور كاملة.

## ماذا تفعل قبل الإعلان للزبائن؟
1. فعّل مدن التوصيل ورسومها؛ كانت كلها معطلة عند المراجعة.
2. راجع المنتجات الحقيقية والصور والأسعار والمخزون، وأوقف المنتجات التجريبية.
3. راجع رقم WhatsApp وسياسة الاستبدال والاسترجاع.
4. فعّل الحماية والنسخ الاحتياطي كما سبق.
5. جرّب القائمة والبحث والمنتج والصور والشات والسلة من هاتفك، بالعربية والإنجليزية والعبرية.
6. نفّذ طلبًا تجريبيًا واضحًا، تحقق من وصوله للأدمن وصحة الرسوم والمخزون، ثم ألغِه من الأدمن وتحقق من عودة الكمية.
7. جرّب حساب جملة وحساب موظف محدودًا وتأكد أن كل واحد يرى ما يخصه.
8. افتح وصول الاستضافة للزبائن عندما تنهي ذلك؛ نشر تحديث الكود لا يغيّر الموقع الخاص تلقائيًا إلى عام.

## حدود الفحص والميزات
نجاح الاختبارات لا يضمن انعدام جميع الأخطاء أو الثغرات. فُحص الكود وTypeScript واختبارات قاعدة البيانات والواجهات البرمجية؛ لم يتوفر متصفح آلي لاختبار كل شاشة ولم ننفذ دفعًا أو توصيلًا حقيقيًا أو استعادة نسخة. المساعد المجاني يعتمد الكتالوج مع AI محلي اختياري، وخدمة AI السحابية غير مفعلة. لا توجد حاليًا بوابة دفع بطاقات متكاملة. احتفظ بملف الكود ودليل التشغيل المرفقين للمطور عند الحاجة.
